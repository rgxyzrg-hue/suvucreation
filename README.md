# Suvu Creation · sample shop website 🎀

A sample website made for [@suvucreation](https://www.instagram.com/suvucreation/), handmade bouquets, bags, hair accessories and gifts.

Live: https://rgxyzrg-hue.github.io/suvucreation/

- Product grid with categories, wishlist and a shopping bag
- Orders go to Suvu as a message (Instagram DM now, WhatsApp when a number is added in `app.js`)
- Prices are placeholders; edit `PRODUCTS` in `app.js`
- Photos: sharp frames taken from her 1080p reels (`img/`)
- Plain HTML/CSS/JS, no build step
